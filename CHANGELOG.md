# Historial

## 0.2.0 — Base modular (2026-09-11)

- Escenas independientes del gato, cámara, HUD, pausa, audio y misión.
- Barrio y cuatro habitaciones editables por separado.
- Estado de sesión y servicio de guardado separados de presentación.
- Iluminación configurable por escena; controles persistidos en Input Map.
- Recorrido automático de regresión y herramientas portables.
- Configuración Git y guía para trabajar entre dos.

El prototipo original Dos Miradas se conserva fuera de este repositorio.
