# Arte del prototipo

Se utilizó la herramienta integrada **image_gen** (sin CLI ni API key). Los recursos seleccionados están incluidos en `assets/`; el juego no depende de sus ubicaciones originales de generación.

El mapa de referencia del usuario se empleó como guía de perspectiva; la ficha del gato, como referencia explícita de diseño. Se generaron imágenes nuevas. El fondo y el gato siguen siendo assets de prototipo, no un sistema completo de tiles y animaciones de producción.

## assets/rooms.png · prompt

Create ONE production-ready pixel art game BACKGROUND ATLAS, exactly 2048x1024 pixels, a strict 2 columns x 2 rows grid of FOUR distinct 1024x512 room images touching at exact center lines, NO dividers, NO labels, NO text, NO characters, NO UI. Each quadrant is a straight-on SIDE VIEW 2D PLATFORMER room cutaway (NOT top down, NOT isometric). Top-left: cozy living room with green sofa, small fireplace at x70% width, bookshelf, amber floorlamp on left, rug, twilight blue window. Top-right: cozy kitchen with copper pans, cream cabinets, herbs, stove, sink, warm hanging lamp at center, a small fish dish on countertop. Bottom-left: bedroom with quilted bed, bedside amber lamp at x68% width, night window, plants and knitted blankets. Bottom-right: bathroom with cream clawfoot tub, blue-green small tiles, round mirror, wooden vanity, flickering candles at x65% width. Unified polished hand placed PIXEL ART with crisp square clusters and restrained outlines, readable 16-bit indie game look, textured wood, dark teal shadows and honey amber warm highlights, dusky night outside. VERY IMPORTANT geometry: in EVERY room, the flat horizontal walkable wood/tile floor begins at exactly 85 percent of that quadrant's height and spans to bottom. Furniture is behind that unobstructed walking strip. Keep bottom 15 percent clear for a cat player to walk. Doors/passages can be added separately by game code so leave side edges uncluttered. Soft cozy lighting already subtle in painting but game will add actual moving light halos. This is an original home interior game asset atlas, not a collage, not a poster. Pixel art, no smooth vector, no photographic rendering.

## assets/cat.png · prompt

Use the attached image ONLY as CHARACTER DESIGN REFERENCE. Create ONE transparent PNG game sprite atlas, 1024x1024 square, strict 4 columns by 4 rows equal 256x256 cells, all backgrounds genuinely transparent. NO text, NO grid, NO floor, NO shadows, NO props other than the cat's collar. Exactly ONE same orange kitten in every cell, centered and full body with tail safely within each cell and feet at 85% of each cell height. Kitten is orange tabby with darker orange stripes, white muzzle/chest/paws, WHITE TAIL TIP, pink inner ears and nose, black small square eyes, RED collar and tiny GOLD BELL. Match the attached orange kitten identity and proportions, adorable oversized head, small quadruped body, upright curled tail. Crisp hand drawn 32-bit PIXEL ART clusters and dark selective outline, not 3D renders, no antialias blur. Row 1: four SIDE PROFILE facing RIGHT walk cycle frames (idle, opposite front/back legs walking, passing stance, alternate stride). Row 2: four SIDE PROFILE facing LEFT walk cycle frames. Row 3: four TOP-DOWN RPG three-quarter view facing DOWN towards viewer, idle then three walking frames. Row 4: four TOP-DOWN RPG three-quarter view facing UP away from viewer showing back of head and white tail tip, idle then three walking frames. Each cat fits a bounding box of about 150x160 pixels within its 256 cell; same scale and anchored feet all 16 frames. Keep generous transparent gutters between cells. This is usable game art, no poster, no annotations, no labels.

El resultado fue RGB con damero, no alfa real. Una segunda solicitud de extracción no produjo alfa y se descartó. Se conserva la primera imagen y se utiliza un shader de clave de color en Godot. La paleta crema cálida del gato permite distinguir el pelaje del damero gris azulado. Las dimensiones generadas difieren de las solicitadas; el código calcula las celdas desde el tamaño real.

## assets/town.png · prompt

Create a single game-ready FULL MAP background illustration for a cozy pixel art RPG, 1536x1024 landscape, camera elevated TOP-DOWN 3/4 orthographic like classic 2D farming RPG towns (NOT a side view, NOT a tilted isometric diamond). Entire rectangular map visible, no UI no labels no letters no characters no cats. Polished crisp square pixel clusters, dark teal/indigo twilight shadows, autumn foliage, brick and cobblestone texture, amber glowing windows and lanterns. Layout EXACT for game integration: a small inviting two-story cottage occupies the LOWER-LEFT quadrant, footprint spanning x=10%-36%, y=33%-64%, warm front door facing DOWN centered at x=24%, y=64%. Cottage has green shutters, red-brown tiled roof, ivy, warm windows, flower pots. Leave clear WALKABLE cobblestone path at y=70%-85% across whole map, connected by a clear vertical path at x=52%-64% leading up toward the upper right. UPPER-RIGHT quadrant is a secluded public GARDEN PLAZA with a small round blue stone fountain centered x=77%, y=38%, benches, three unlit decorative lantern plinths nearby, a hanging string of warm lights and trees around perimeter, open walking space. A tiny closed flower kiosk upper-left adds neighborhood charm. Clear connected walkable paths must connect home door to garden fountain; no fences blocking them. Foreground low flowers only, vegetation clustered around outer edges, moderate prop density so paths are readable. Warm lampposts on BOTH sides of the path around x=43%,y=73% and x=64%,y=63% and x=68%,y=27%. NO snow. Nighttime cozy, luminous amber pools against blue stone paving, dense enough pixel art details to feel like a real handcrafted game map. No vignette, no borders, no watermarks. Static BACKGROUND only, gameplay characters and dynamic glows will be added by engine.

Las áreas transitables y las luces se ajustaron al resultado generado, no a las coordenadas hipotéticas del prompt. El arte pintado aporta parte del ambiente; las luces interactivas se implementaron con nodos de Godot.
